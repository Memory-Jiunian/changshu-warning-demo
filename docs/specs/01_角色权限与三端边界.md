# 01 角色权限与三端边界

## 1. 权限矩阵

| 角色 | 可查看 | 可操作 | 禁止 |
|---|---|---|---|
| 班主任 | 自己班级中被分配任务所需的有限学生信息、任务说明、截止时间、自己的历史反馈 | 主动异常上报、提交/补充事实观察、确认已提醒学生复测 | 风险定级、确认预警、查看完整测评或 AI 对话、查看其他班级个案、修改主状态 |
| 年级主任 | 被指派或超时事项的必要信息、班主任完成进度、督办历史 | 提醒班主任、记录协调与督办、标记已联系 | 查看完整个案、查看心理老师干预内容、风险定级、代替班主任填写观察 |
| 心理老师 | 小程序中可选的协作进度摘要 | 查看任务反馈是否到达；不做主要专业操作 | 在小程序完成复核、干预、转介、闭环等管理终端行为 |
| 校长 | 本轮无个案入口 | 无 | 查看小程序学生个案或协作正文 |

---

## 2. 最小信息原则

### 班主任任务详情允许展示

- 学生姓名；
- 年级 / 班级；
- 任务类型；
- 任务目的；
- 心理老师给出的非诊断性注意事项；
- 需要观察的维度；
- 截止时间；
- 自己已提交的反馈；
- 当前提交状态。

### 不展示

- 完整量表题目与得分明细；
- 完整 AI 倾诉对话；
- 心理老师专业研判正文；
- 转介机构与敏感原因；
- 其他老师的完整反馈；
- 其他学生数据；
- 风险算法的内部评分。

风险等级是否展示：

- 默认不向班主任展示“中风险 / 高风险 / 危险”标签；
- 使用“需关注”“需优先关注”等任务级提示；
- Demo 若必须体现优先级，应展示任务紧急程度，而不是让班主任看到专业风险定级。

## 3. 数据可见范围

### 班主任

```text
user.role = head_teacher
AND task.assigneeId = user.id
```

主动上报历史仅展示本人提交，不能查询全校线索池。

### 年级主任

```text
user.role = grade_director
AND (
  task.supervisorId = user.id
  OR task.gradeId in user.managedGradeIds
)
AND task.needSupervision = true
```

年级主任列表默认只展示协作进度和必要身份信息，不显示反馈正文预览。

### 心理老师

小程序 Demo 若提供查看入口，只读取协作摘要；专业详情跳转提示“请前往管理终端处理”。

---

## 4. 隐私交互规则

1. 从任务列表进入详情，页面标题不使用“心理疾病”“异常学生”等标签；
2. 最近任务卡片不显示敏感反馈正文；
3. 切到后台再返回时，敏感详情页应显示隐私遮罩或重新确认进入；
4. 分享、复制、截屏提示属于 P1，不阻塞 MVP；
5. 空状态不能使用“所有学生都很健康”等绝对结论；
6. 演示 mock 姓名、班级和描述均使用虚构数据；
7. 错误日志不得输出完整敏感正文。

---

## 5. 即时安全风险提示

观察表单可提供“是否发现需要立即线下处理的安全风险”单选，但其作用只是：

- 弹出强提示；
- 告知先按学校现有线下应急流程处理；
- 表单记录不能替代电话、当面报告或既有应急机制；
- 不在 Demo 中自行设计真实报警或医疗转介流程。

选择“是”后仍可保存事实记录，但按钮文案与提示必须明确线下处置优先。
