# Phase 4.7B 紧凑工作模式评审

## 评审范围

本轮仅调整班主任核心工作链路的展示密度：

- 班主任首页；
- 任务列表；
- 待反馈任务详情；
- 填写观察反馈；
- 上述页面直接使用的任务行、单选组、文本域、页头和样式。

Repository、Provider、权限、任务状态、超时派生、筛选结果、字段定义、校验、草稿、请求去重、提交和状态同步均未改变。异常上报、复测详情、年级主任页面未迁移。

## Compact Work Density

工作页面采用以下密度基线：

- 页面左右边距 16px；
- 一级区块间距 16px，紧密关联内容间距 8–12px；
- 普通内容内边距 12–14px；
- 普通列表行最小高度 72px；
- 含摘要任务行目标高度 88–110px；
- 表单控件可视高度 40–44px；
- Filter / Choice Chip 可视高度 32–36px；
- 工作页面 H1 20–22px，区块标题 16–17px，正文 14px，辅助信息 12px；
- 普通信息区不使用阴影，不为每个区块创建 Card；
- 连续信息优先使用分割线；
- 低频可选内容采用渐进披露。

可访问性保护：

- 可点击区域不小于 44×44px；
- Chip 可视高度为 34px，外层点击区域为 44px；
- 字号不低于 12px；
- 状态同时使用文字，不只依赖颜色；
- 固定操作栏保留足够页面底部滚动空间。

## 页面结果

### 班主任首页

原问题：

- 重点任务和普通任务使用近似尺寸；
- 三张统计卡占用过多纵向空间；
- 复测和上报入口使用完整模块表达。

V2.1：

- 重点任务保留展开表达，实测 107.89px；
- 第二、第三项改为连续列表行，实测均为 88.14px；
- 三项统计合并为 60px 连续统计条；
- 今日复测改为 64px 信息行；
- 主动上报改为紧凑入口行；
- 844px 首屏已出现今日复测入口。

删除的容器：

- 第二、第三项独立 Card；
- 三张独立统计 Card；
- 复测提醒和主动上报的大按钮容器。

### 任务列表

原问题：

- 每条任务使用独立圆角 Card；
- 条目间距和容器边界重复；
- 筛选可视高度与触控高度没有分离。

V2.1：

- 四条任务进入一个连续白色内容面，以分割线分组；
- 单条任务统一为 96px；
- 每条只保留一个主状态 Badge；
- 任务类型、摘要和时间保持三层文字结构；
- Segmented Control 保持 40–44px；
- 筛选可视高度 34px，外层点击区 44px；
- 不存在 `.mvp-teacher-task-card` 独立 Card。

### 待反馈任务详情

原问题：

- 两个内容 Card 权重相近；
- Grid 默认拉伸导致少量内容填满 844px；
- 无历史记录时仍有形成空区块的风险。

V2.1：

- 页头实测 60px；
- 状态、学生、任务目的和观察重点合并为一个连续内容面；
- 内容面实测 364.75px，在页面 456.75px 位置结束；
- 元数据和任务内容使用分割线；
- 观察重点改为一行文本序列；
- 无反馈记录时不渲染历史标题或空状态；
- 只有一个固定主操作，且不显示底部导航。

### 观察反馈

原问题：

- 初始页面达到 1767px；
- 场景和频率使用大单选卡；
- 低频可选字段始终展开；
- 底部主次按钮占据同等空间。

V2.1：

- 表单移除大外层卡片，改为平铺字段组与分割线；
- 场景和频率改为紧凑 Choice Chips；
- 事实文本域初始 4 行，输入后自动增高，达到上限后内部滚动；
- 字数和事实提示合并到同一辅助行；
- 填写示例保留为默认关闭的文本折叠；
- 出现频率、持续时间、补充说明默认折叠；
- 草稿中存在任一可选字段时自动展开，实测刷新后可恢复；
- 安全风险改为紧凑横向选项，选择“是”后仍显示完整强提示；
- 固定操作栏只保留“提交观察反馈”，返回由页头处理；
- 折叠态 1067px，展开态 1422px。

## 回归与可访问性

- 首页和任务列表保留底部导航；
- 详情和表单不渲染底部导航；
- 表单固定操作区只有一个按钮；

- 草稿含可选字段时刷新后自动展开并恢复；
- 提交保存用户实际输入；
- 提交后任务从待反馈筛选移除；
- 详情显示最新事实记录。
