# 07 UI 设计系统

## 1. 视觉方向

目标是形成亲和、可信、克制的健康服务类移动体验，延续此前偏“蚂蚁阿福”式的清晰层级和轻量卡片感，但不做像素级复制。

视觉关键词：

- 亲和；
- 安静；
- 清晰；
- 可信；
- 低认知负担；
- 不制造恐慌。

---

## 2. 技术原则

当前项目使用纯 CSS 和轻量 `shadcn-inspired` 组件，不引入完整 shadcn/ui、Tailwind 或 Radix。

所有样式通过 token 管理，页面内禁止散落硬编码色值和阴影。

---

## 4. 字体层级

| 用途 | 字号 | 行高 | 字重 |
|---|---:|---:|---:|
| 页面标题 | 24 | 32 | 700 |
| 区块标题 | 18 | 26 | 600 |
| 卡片标题 | 16 | 24 | 600 |
| 正文 | 15–16 | 24 | 400 |
| 辅助信息 | 13–14 | 20 | 400 |
| 数字概览 | 28–32 | 36 | 700 |

避免同一页面出现过多字号。优先用字重、间距和位置建立层级。

## 6. 卡片规则

- 卡片内边距 16px；
- 卡片间距 12px；
- 主信息与辅助信息间距至少 8px；
- 一张卡只表达一个任务；
- 任务原因最多两行；
- 超时标签不使用高饱和大面积红色；
- 卡片阴影克制，主要依靠背景和边框区分。

---

## 7. 状态颜色

颜色只辅助，不单独承载含义。

| 状态 | 语义 |
|---|---|
| 待反馈 | 信息蓝 |
| 今日到期 | 警示橙 |
| 已超时 | 危险红 |
| 待补充 | 警示橙 |
| 已提交 | 成功绿 |
| 已完成 | 中性绿 / 灰 |
| 已取消 | 中性灰 |

---

## 8. 图标

- 使用同一套线性图标库；
- 图标大小以 18/20/24px 为主；
- 不使用表情符号替代业务图标；
- 图标必须配文字，除非含义完全明确；
- 高风险场景不使用夸张警报、骷髅、闪电等制造恐慌的符号。

---

## 9. 页面布局

- 页面左右边距 16px；
- 顶部身份区和任务概览形成第一视觉层；
- 卡片列表保持垂直单列；
- 长表单分组，不做双列；
- 底部操作区与系统安全区适配；
- 360px 宽度下不得横向滚动。

---

## 10. 动效

- 页面切换 160–220ms；
- 卡片展开不超过 200ms；
- 成功状态可轻微淡入；
- 不使用大幅弹跳和庆祝动效；
- 即时安全风险提示使用稳定、明确的模态反馈。
