## 3. 必要重复

以下重复属于安全或行动所需，不删除：

1. **首页超时数量 + 超时提醒条**：数量负责进入筛选，提醒条负责指出优先行动，语义不同。
2. **异常上报安全提示 + 提交确认提示**：前者在选择“是”后持续可见，后者在不可逆提交前再次确认，属于安全必要重复。
3. **历史记录中的提交时间 + 页面当前状态**：一个用于追溯事件，一个用于说明当前行动，两者层级不同。

## 4. 状态与操作规则

- 任务详情仅渲染一个主状态 Badge。
- 普通任务仅 `pending` 和 `returned` 显示底部操作区。
- 复测提醒仅待提醒状态显示底部操作区。
- 已提交、已完成、已取消状态不再以禁用主按钮表达结果。
- 取消状态统一使用中性样式，并保留原计划时间作为历史信息。
- `overdue` 继续由截止时间和任务状态派生，不写入任务状态。

## 5. 回归结论

浏览器已完成以下链路：

1. 普通观察反馈提交后，详情、待反馈筛选和状态同步。
2. 退回任务补充后，原记录保留并新增关联记录。
3. 异常上报提交后，可从成功页进入刚提交记录的只读详情。
4. 复测确认后进入“已提醒，等待学生完成”，且无禁用底部按钮。
5. 年级主任直接访问班主任任务时仍被统一权限拦截。

本轮没有改变任务筛选结果、反馈写入、草稿恢复、异常上报、复测确认、权限、状态同步或请求去重规则。
