# 09 验收矩阵

## A. 角色与隐私

- [ ] 班主任只能看到本人负责班级的任务；
- [ ] 年级主任只看到待督办或明确指派事项；
- [ ] 校长没有小程序个案入口；
- [ ] 班主任看不到完整测评、AI 对话和心理老师研判；
- [ ] 年级主任看不到完整反馈正文；
- [ ] 页面不要求班主任选择风险等级；
- [ ] 列表不显示敏感反馈摘要；
- [ ] 无权限 URL 进入时显示无权限页。

## B. 默认协作任务

- [ ] 确认正式预警后生成一条默认班主任任务；
- [ ] 任务首页数量增加；
- [ ] 首次打开记录已读时间；
- [ ] 未提交前状态为 pending；
- [ ] 提交后新增反馈记录；
- [ ] 原任务状态变为 submitted；
- [ ] 管理终端可读取该记录；
- [ ] 不修改 WarningStatus。

## C. 额外反馈请求

- [ ] 每次请求生成独立任务或请求记录；
- [ ] 不覆盖默认协作任务；
- [ ] 任务说明显示本次观察重点；
- [ ] 超时根据 dueAt 派生；
- [ ] 提交后历史反馈都保留。

## D. 退回补充

- [ ] 心理老师退回后任务显示待补充；
- [ ] 退回原因清晰；
- [ ] 原反馈只读保留；
- [ ] 补充提交生成新记录；
- [ ] 新记录关联旧记录；
- [ ] 不覆盖原正文。

## E. 异常上报

- [ ] 班主任能选择本人班级学生；
- [ ] 表单强调填写事实；
- [ ] 不能填写风险等级；
- [ ] 安全风险选择“是”时显示线下处置优先提示；
- [ ] 提交后管理终端生成班主任上报线索；
- [ ] 不自动确认正式预警；
- [ ] 成功页不显示诊断结论。

## F. 复测提醒

- [ ] 只有管理终端安排复测后才生成；
- [ ] 班主任能查看时间和提醒要求；
- [ ] 班主任只能确认已提醒；
- [ ] 班主任不能录入复测结果；
- [ ] 转介结果不会自动生成提醒；
- [ ] 学生完成复测后提醒状态同步；
- [ ] 管理终端仍由心理老师更新主状态。

## G. 年级主任督办

- [ ] 超时或明确指派后进入督办列表；
- [ ] 不满足条件时不可见；
- [ ] 督办记录新增且保留历史；
- [ ] 督办不会代替班主任完成任务；
- [ ] 年级主任不能修改风险等级和主状态；
- [ ] 默认不展示反馈正文。

## H. 页面状态

- [ ] 加载态；
- [ ] 空状态；
- [ ] 局部失败；
- [ ] 整页失败；
- [ ] 离线状态；
- [ ] 无权限；
- [ ] 已取消；
- [ ] 已完成；
- [ ] 重复提交保护；
- [ ] 返回后筛选和滚动恢复。

## I. UI 与移动端

- [ ] 360px 宽度无横向滚动；
- [ ] 主要点击区至少 44×44px；
- [ ] 正文字号不小于 14px；
- [ ] 状态不只靠颜色；
- [ ] 底部按钮不被安全区或键盘遮挡；
- [ ] 同类页面使用统一卡片、表单和状态组件；
- [ ] 图标来自同一图标库；
- [ ] 页面层级符合对比、亲密、对齐、重复四原则；
- [ ] 不使用大面积高饱和红色制造恐慌。

## J. 工程

- [ ] `npm run build` 通过；
- [ ] TypeScript 无新增错误；
- [ ] 无无理由 `any`；
- [ ] 任务数据来自统一真值；
- [ ] 页面不直接写入 mock 数组；
- [ ] 无新增未批准重型依赖；
- [ ] 关键操作有 Result 错误处理；
- [ ] 本地草稿带版本号；
- [ ] 旧页面可按阶段回滚。

---

## 作品集演示必跑的三条链路

### 链路 1：正式预警后的协作

```text
班主任首页
→ 打开待反馈任务
→ 查看任务目的
→ 填写事实观察
→ 提交
→ 详情出现新记录
→ 首页待办数量减少
```

### 链路 2：主动异常上报

```text
上报
→ 选择学生
→ 填写事实
→ 提交
→ 显示“已提交给心理老师复核”
```

### 链路 3：复测与督办

```text
班主任确认已提醒学生复测
→ 切换年级主任
→ 查看一条超时事项
→ 记录督办
→ 原班主任任务仍未被代办完成
```
