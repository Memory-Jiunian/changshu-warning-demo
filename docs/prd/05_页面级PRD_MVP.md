# 05 页面级 PRD（MVP）

## 1. Demo 角色选择

### 目标

让作品集演示者快速切换班主任和年级主任，验证角色差异。

### 页面内容

- 项目名称；
- 两个角色卡片；
- 角色核心任务说明；
- “进入演示”。

### 规则

- 角色切换只影响前端 mock 权限；
- 页面明确标注“演示模式”；
- 不模拟账号密码。

---

## 2. 班主任首页

### 用户问题

> 我今天有哪些必须处理的协作任务？

### 页面结构

1. 顶部身份区；
2. 三个概览：
   - 待处理；
   - 已超时；
   - 今日提醒；
3. 今日复测提醒卡；
4. 最近待办列表，最多 3 条；
5. 主动上报异常入口；
6. 最近提交结果。

### 待办卡字段

- 学生姓名；
- 班级；
- 任务类型；
- 为什么需要处理；
- 截止时间；
- “已超时 / 今日到期 / 待补充”标签；
- 操作：`查看任务`。

不展示专业风险等级。

### 空状态

- 无待办：`当前没有需要处理的协作任务`
- 无复测：`今天没有需要提醒的复测安排`

---

## 3. 班主任任务列表

### 筛选

- 全部；
- 待反馈；
- 待补充；
- 复测提醒；
- 已提交；
- 已完成。

### 行为

- 筛选结果为空时展示对应文案；
- 返回后保留筛选与滚动；
- 数量从统一任务集合派生；
- 取消任务显示为历史，不进入待办。

---

## 4. 协作任务详情

### 页面目的

让班主任在不接触专业隐私的前提下，明确“为什么找我、我要观察什么、何时提交”。

### 页面结构

#### A. 状态摘要

- 任务类型；
- 当前状态；
- 截止时间；
- 是否超时。

#### B. 学生有限信息

- 姓名；
- 年级 / 班级；
- 与当前任务有关的基本说明。

#### C. 任务说明

- 发起人：心理老师；
- 发起时间；
- 本次观察目的；
- 建议观察维度；
- 非诊断性注意事项。

#### D. 我的反馈记录

- 提交时间；
- 观察时间；
- 事实摘要；
- 状态：已提交 / 待补充 / 已完成；
- 退回原因（如有）。

#### E. 底部操作

- pending：`填写观察反馈`
- returned：`补充反馈`
- submitted：禁用按钮 `等待心理老师查看`
- completed：`任务已完成`
- cancelled：`任务已取消`

### 异常态

- 任务不存在；
- 无权限；
- 已取消；
- 数据加载失败；
- 网络断开。

---

## 5. 填写观察反馈

### 表单字段

| 字段 | 必填 | 规则 |
|---|---|---|
| 观察时间 | 是 | 不晚于当前时间 |
| 观察场景 | 是 | 课堂 / 课间 / 宿舍 / 活动 / 沟通 / 其他 |
| 事实观察 | 是 | 20–500 字，提示写可观察行为 |
| 出现频率 | 否 | 首次 / 偶尔 / 多次 / 持续 |
| 持续时间 | 否 | 简短文本 |
| 是否存在需要立即线下处理的安全风险 | 是 | 是 / 否 |
| 补充说明 | 否 | 0–300 字 |

### 文案指导

推荐提示：

> 请描述你实际看到或听到的行为、发生时间和场景，避免填写心理诊断或人格评价。

不推荐示例：

- “他有抑郁症”
- “她性格有问题”
- “他就是装的”

推荐示例：

- “7 月 15 日午休时独自趴在座位约 40 分钟，两次拒绝同学邀请，回应声音较小。”

### 提交流程

```text
点击提交
→ 二次确认摘要
→ 防重复提交
→ 写入新记录
→ 返回任务详情
→ 展示成功状态
```

### 草稿

- 离开页面时提示保存草稿；
- 草稿按 `taskId` 保存；
- 任务取消后草稿只允许复制，不允许提交。

## 6. 主动上报异常

### 页面目的

让班主任在没有正式协作任务时，提交一线事实线索。

### 字段

- 选择学生；
- 观察时间；
- 观察场景；
- 事实描述；
- 已采取的线下沟通或支持；
- 是否存在需要立即线下处理的安全风险；
- 联系方式确认。

### 提交成功

显示：

- `已提交给心理老师进行专业复核`
- 记录编号；
- 提交时间；
- 查看本人上报记录。

不得显示：

- “已确认高风险”
- “系统判断为抑郁”
- “已正式预警”

---

## 7. 复测提醒详情

### 展示

- 学生姓名；
- 班级；
- 复测日期和时间；
- 复测方式或地点；
- 提醒要求；
- 当前状态；
- 操作记录。

### 操作

- `确认已提醒学生`
- 可补充提醒方式：当面 / 班级消息 / 电话；
- 不允许填写复测结果；
- 学生完成后系统自动更新，不由班主任操作。

---

## 8. 年级主任首页

### 页面目标

聚合需要协调的超时或明确指派事项。

### 概览

- 待督办；
- 已超时；
- 今日新增。

### 列表字段

- 班级；
- 班主任；
- 任务类型；
- 超时时长；
- 最近督办时间；
- 操作：`查看督办`。

默认不显示反馈正文和专业风险等级。

---

## 9. 督办详情

### 展示

- 班级与班主任；
- 任务类型；
- 创建和截止时间；
- 当前进度；
- 已有督办记录；
- 最小学生身份信息，仅在确有必要时展示姓名。

### 操作

- 选择督办方式；
- 填写事实性督办结果；
- 提交记录。

### 禁止

- 代替班主任填写观察；
- 修改任务完成状态；
- 查看心理老师干预内容；
- 给学生风险定级。
